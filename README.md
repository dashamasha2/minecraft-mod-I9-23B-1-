# Команда йоу

## Участники:
Грапп Мария, Клетнов Арсений, Макарова Дарья

## Цель проекта:
Создание мода для Minecraft — декоративный «Сапфирово-розовый блок».

## Структура проекта
* `src/main/java` — исходный код программы (Java-классы).
* `src/main/resources` — ресурсы и файлы конфигурации (fabric.mod.json).
